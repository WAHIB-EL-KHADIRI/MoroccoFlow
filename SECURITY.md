# Security Policy

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it privately rather than opening a public issue.

Contact the maintainer directly with:
- A description of the vulnerability
- Steps to reproduce it
- Any relevant logs or proof-of-concept code

Please allow reasonable time for a response and fix before any public disclosure.

## Scope

This policy covers the code in this repository. It does not cover third-party dependencies, which should be reported to their respective maintainers.
